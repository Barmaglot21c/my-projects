## Примеры пет-проектов

### 1. **Transport Catalogue**
Транспортный справочник, реализующий базу данных маршрутов общественного транспорта. Проект предоставляет функционал для вывода статистики по маршрутам и остановкам, построения оптимальных маршрутов и визуализации карты маршрутной сети.

**Технологии и подходы:**
- Парсинг JSON для обработки входных данных и формирования ответов
- Реализация графовой модели маршрутной сети
- Поиск кратчайших путей в графе
- Генерация SVG для визуализации карты
- Применение паттерна Builder для работы с внутренней json структурой

---

### 2. **Spreadsheet**
Электронная таблица с поддержкой рекурсивного вычисления формул. Позволяет создавать ячейки с текстовым, числовым содержимым и формулами, включая ссылки на другие ячейки.

**Технологии и подходы:**
- Сборка проекта через CMake
- Генерация парсера формул с помощью ANTLR
- Обработка циклических зависимостей при вычислениях

---

### 3. **TicTacToe**
Классическая игра "Крестики-нолики" с графическим интерфейсом на основе спрайтовой графики.

**Технологии и подходы:**
- Разработка GUI с использованием SDL2
- Обработка пользовательского ввода через `SDL_Event`
- Отображение спрайтовой графики

---

### 4. **Image Converter**
Конвертер растровых изображений, поддерживающий форматы JPEG, BMP и PPM.

**Технологии и подходы:**
- Работа с бинарными форматами файлов
- Реализация декодирования/кодирования в соответствии со спецификациями форматов

---

### 5. **STL Containers**
Кастомная реализация стандартных контейнеров `vector` и `forward_list`.

**Технологии и подходы:**
- Ручное управление динамической памятью
- Реализация итераторов
- Соблюдение семантики стандартной библиотеки C++
