# Проект: транспортный справочник

Программа хранит данные о маршрутах автобусов, их остановках. По запросу выводит данные об остановке, маршруту, прокладывает кратчайший путь по заданным остановкам, выводит карту маршрутов. Ввод и вывод данных осуществляется в формате json.

## Формат ввода данных:

### Общая структура
Входные данные представляют собой JSON-объект со следующими основными разделами:

```json
{
    "base_requests": [],      // Запросы на добавление в базу данных (автобусы, остановки)
    "render_settings": {},    // Настройки визуализации карты
    "routing_settings": {},   // Настройки маршрутизации (время ожидания, скорость автобусов)
    "stat_requests": []       // Запросы на получение данных
}
```
### 1. Запросы на добавление в базу данных (base_requests)
Массив объектов, описывающих автобусы и остановки. Может содержать элементы двух типов.

1.1. Маршрут (type: "Bus")

```json
{
    "type": "Bus",
    "name": "Название маршрута",
    "is_roundtrip": true,                   // Кольцевой маршрут (true) или обычный (false)
    "stops": [                              // Список остановок по порядку
        "Остановка 1",
        "Остановка 2",
        "Остановка 3",
        ...,
        "Остановка 1"
    ]
}
```

Для кольцевого маршрута (is_roundtrip: true) первая и последняя остановки должны совпадать
Для обычного маршрута (is_roundtrip: false) список остановок задается в прямом направлении, обратное направление строится автоматически.

1.2. Остановка (type: "Stop")

```json
{
    "type": "Stop",
    "name": "Название остановки",
    "latitude": 55.574371,                     // Широта
    "longitude": 37.6517,                      // Долгота
    "road_distances": {                        // [Опционально] Расстояния в метрах до других остановок
        "Название остановки": 2600,
        ...
    }
}
```
Особенности:

Расстояния указываются только в прямом направлении (от данной остановки до других)
Если расстояние не указано, дорога считается прямой и значение вычисляется по географическим координатам остановок.

### 2. Настройки визуализации (render_settings)
Объект с настройками отрисовки SVG-карты:
```json
{
    "width": 200,                                // Ширина изображения в пикселях
    "height": 200,                               // Высота изображения в пикселях
    "padding": 30,                               // Отступ от краёв до карты
    
    "line_width": 14,                            // Толщина линий маршрутов
    "stop_radius": 5,                            // Радиус точек остановок
    
    "bus_label_font_size": 20,                   // Размер шрифта названий автобусов
    "bus_label_offset": [7, 15],                 // Смещение подписи маршрута от остановок [dx, dy]
    
    "stop_label_font_size": 20,                  // Размер шрифта названий остановок
    "stop_label_offset": [7, -3],                // Смещение подписи остановки [dx, dy]
    
    "underlayer_color": [255, 255, 255, 0.85],   // Цвет обводки текста (RGB или RGBA)
    "underlayer_width": 3,                       // Толщина обводки текста
    
    "color_palette": [                           // Палитра цветов для маршрутов
        "green",                                 
        [255, 160, 0],                           
        "red"                                    
    ]
}
```
Форматы цветов:
Именованные: "red", "green", "blue", "black", "white" и т.д.
RGB-массив: [255, 160, 0]
RGBA-массив: [255, 255, 255, 0.85] (последний элемент — прозрачность от 0 до 1)

### 3. Настройки маршрутизации (routing_settings)

Эти параметры используются для поиска кратчайшего пути.
```json
{
    "bus_wait_time": 6,         // Время ожидания автобуса на остановке (в минутах)
    "bus_velocity": 40          // Скорость автобуса (км/ч)
}
```

### 4. Запросы на получение данных (stat_requests)
Массив объектов, описывающих запросы к сформированной базе данных. Поддерживаются четыре типа запросов.

4.1. Информация об автобусе (type: "Bus")
```json
{
    "id": 1,                        // Уникальный идентификатор запроса
    "type": "Bus",
    "name": "Название автобуса"
}
```

Формат вывода:
```json
{
    "request_id": 1,                // Уникальный идентификатор запроса
    "route_length": 5990,           // Длина маршрута в метрах
    "curvature": 1.42963,           // Извилистость маршрута (географическая длина / фактическое расстояние)
    "stop_count": 4,                // Количество остановок на маршруте (включая повторения)
    "unique_stop_count": 3          // Количество уникальных остановок
}
```
4.2. Информация об остановке (type: "Stop")
```json
{
    "id": 2,                        // Уникальный идентификатор запроса
    "type": "Stop",
    "name": "Название остановки"
}
```
Формат вывода:
```json
{
  "request_id": 2,                   // Уникальный идентификатор запроса
    "buses": [                       // Список автобусов, проходящих через остановку
        "297",
        "635"
    ]
}
```
4.3. Построение маршрута (type: "Route")
```json
{
    "id": 3,
    "type": "Route",
    "from": "Начальная остановка",
    "to": "Конечная остановка"
}
```
Формат вывода:
```json
{
    "request_id": 3,                   // Уникальный идентификатор запроса
    "items": [                         // Пошаговое описание пути: ожидание автобуса (type: "Wait"), время в пути (type: "Bus")
        {
            "type": "Wait",
            "stop_name": "Название остановки",
            "time": 6                  // Время ожидания в минутах
        },
        {
            "type": "Bus",
            "bus": "Название маршрута",
            "span_count": 2,           // Количество остановок без пересадок
            "time": 5.235,             // Время в пути в минутах
        }
    ],
    "total_time": 11.235                // Общее время в минутах
}
```

4.4. Получение карты (type: "Map")
```json
{
    "id": 4,                   // Уникальный идентификатор запроса
    "type": "Map",
    "path": "img/general map"   // [Опционально, в планах] Путь для сохранения карты
}
```
Формат вывода:
```json
{
    "request_id": 4,
    "map": "<?xml version=\"1.0\" encoding=\"UTF-8\" ?>\n<svg ... </svg>"  // svg код с экранированием
    
}
```
Если не указан путь сохранения карты, ответ выводится только в json
